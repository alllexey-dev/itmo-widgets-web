# Statistics - `/admin/dashboard`, administrator

Opened from Главная ("За 7 дней"); the rail keeps Главная active. Totals cover
users, active devices, web sign-ins, friendships, sport queues and open
moderation cases. Three charts show new users, active devices and new links for
30 days on `@alllexey/ui/chart` (uPlot, coloured `--md-primary`); link counts
are grouped by status, and the table "Данные по дням" holds the values the
charts are drawn from.
